# Garden Trauma

A small 3D toy tower defense game built in Godot 4.7. It is also a learning project: the scenes, data, and tools are kept understandable so new mechanics can be explored in small steps.

Open `project.godot` in Godot and press **F5**. Choose **Start** to play Garden 1; winning it unlocks Garden 2. The [documentation home](docs/index.md) links to the playing, level building, data, and asset guides, plus a separate [roadmap](docs/roadmap/index.md) showing current progress and open questions.

To read the docs locally with MkDocs Material:

```powershell
python -m mkdocs serve
```

Run `python -m mkdocs build --strict` to validate the site. See [Getting started](docs/guides/getting-started.md) for Godot scenes and checks.
