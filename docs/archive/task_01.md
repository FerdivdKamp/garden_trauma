Create a small scene to test / demonstrate a tower.

The tower is in the centre. Towers have 2 circles. On outer circle for detecting enemies and an inner circle hich demonstrates the range. 

The scene should have sliders and fields to fill in values.

There should be an enemy pawn whose distance from the tower is also controlled by a slider for testing / demonstrating.

The tower can be a set of basic shapes. it should have a turret that can rotate. There should be a reset button in the scene that makes the barrel point in the opposite direction of the enemy. Turn speed is another value that should be adjustable in the scene. There should be a dropdown selector of towers. Make a simple second tower with a double barrel, simply so the dropdown can act as a selector.

The enemy can be a simple sphere.

Note that we expect to be using blender later as described in the toy_tower_defense_design.md

Please include unittests.

The pawn has health points which are adjustable and the tower has a damage number which should be adjustable. There should be a save button for saving tower params and one for saving pawn params.
