# Garden Trauma documentation

Garden Trauma is a small 3D toy tower defense game and a Godot learning project. The current build has two playable garden levels. You place towers, start waves, protect the objective, and unlock the second garden by winning the first.

Use the sections according to what you need:

- **Guides** explain how to run and change the project. Start with [Getting started](guides/getting-started.md), then try [Playing and testing](guides/playing-and-testing.md).
- [Level dressing](guides/level-dressing.md) explains scatter settings and how to add pebbles.
- **Reference** records the project layout and [audio provenance](reference/audio-sources.md).
- **Roadmap** shows [what is implemented](roadmap/index.md), [what comes next](roadmap/next.md), and longer design proposals. Planned ideas are proposals until tested in the game.
- **History** preserves original task requests and the completed skeleton checklist. They describe earlier stages and should not be used as current instructions.

For the game concept and possible longer campaign, read the [game design notes](roadmap/plans/game-design.md). The [current status](roadmap/index.md) is the source for what exists in this repository now.
